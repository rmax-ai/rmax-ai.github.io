# Apps and descriptions

| App | Description | What you can do | Screenshot |
| --- | --- | --- | --- |
| Agent Font Compare | Compare UI/monospace fonts for AI interfaces with real sample text (Rust code). | Choose UI and code fonts, switch scenarios, copy code snippets, toggle dark mode. | `agent-font-compare.png` |
| Gemini Multiturn TTS Demo | Script-driven interface for multi-speaker dialogues using Gemini voices. | Configure speakers/voices, add/import/export dialogue, set style instructions, provide Gemini API key, generate audio. | `multiturn-demo.png` |
| Lotta Ari Assistant (private) | Brazilian Portuguese voice tutor offering accent labs, contrast drills, and lesson mode. | Tap to start speaking, choose Accent Lab, Contrast, or Lesson Mode, practice with microphone. | `lotta-ari-assistant.png` |
| Maxi-Tutor (preview) | Spanish coach (Rioplatense accent) that guides you through conversations and lessons. | Enter name, accept terms, explore conversation/lesson/accent tools, start mic-led practice. | `maxi-tutor-preview.png` |
| IdeaPad (preview) | Creative partner that captures idea sessions with persona controls and a notepad. | Provide name, accept terms, activate Anchor persona, clear memory, review idea log. | `ideapad-preview.png` |
| Gemma Voice Assistant (private) | Voice-first companion with persona buttons, notepad, and idea tracking. | Tap to talk, toggle captions, open notepad, end session, switch personas. | `gemma-assistant.png` |
| Zelf Reflection (Zen Companion preview) | Reflective companion emphasizing calm, memory, and guided presence. | Enter name, accept terms, manage memory/notes, adjust presence/music presets, enter reflection space. | `zelf-preview.png` |
